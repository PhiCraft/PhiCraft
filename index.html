Phira 谱面编辑 · 重制 · 融合PhiCraft

轻量、高效的谱面工具，支持音符批量转换、流速调节、长条切割、铺面融合、镜像偏移，内置 C++ 加速引擎。

核心功能

六大模块，覆盖谱面制作全流程

I

谱面信息

修改曲名、艺术家、谱师、BPM 及封面曲绘，一键保存生效。

N

音符转换

Tap、Drag、Flick 与长条之间的批量转换，支持多选文件同时处理。

S

流速与切割

整体倍率缩放或固定流速，并将长条拆分为密集短音符。

F

铺面融合

合并多个 .json 谱面，自动处理不同 BPM 并统一输出。

M

偏移与镜像

按拍数偏移复制所有判定线，或一键左右镜像翻转。

C

C++ 加速引擎

内置 phi_plugin.dll，音符处理与偏移复制性能提升数倍。

能力演示

直观感受谱面编辑的流畅与精准

批量音符转换

选中多个谱面文件，一键将 Tap 转为 Drag，或将长条切割为 Tap。

→ 选中 3 个文件 · 转换类型：Tap → Drag
→ 共处理 1,247 个音符

铺面融合

将多个不同 BPM 的谱面合并为一个，自动重采样，输出统一节奏。

→ 源文件：A.json (140BPM) + B.json (160BPM)
→ 合并后：190 条判定线，BPM 统一为 140

流速与切割

整体流速倍率缩放，或固定为指定值。长条可自动切割为密集短音符。

→ 流速倍率 1.25× · 切割每拍 4 份 → 长条数减少 80%
